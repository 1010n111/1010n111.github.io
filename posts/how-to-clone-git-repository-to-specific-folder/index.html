常见问题

克隆到现有非空目录

克隆到现有目录时，该目录必须为空。若目录非空，可先清空目录或使用其他方法（如 git init、git remote add 和 git fetch）来合并代码。

.git 文件夹隐藏

在大多数图形文件浏览器中，.git 文件夹是隐藏的。确保在文件浏览器中显示隐藏文件，以便进行相关操作。
