Python类为何要继承object

技术背景

在Python发展历程中，类有“旧风格（classic）”和“新风格（new）”之分。Python 2.2引入了新风格类，在Python 2.x里，类的定义因是否继承object而分为这两种风格；到了Python 3.x，仅存在新风格类。理解为何Python类要继承object，对于掌握Python类的特性及避免潜在问题至关重要。

实现步骤

Python 2.x

在Python 2.x中，有如下两种类风格：

  • 旧风格类：不将object作为基类。
  • 新风格类：直接或间接将object作为基类。

最佳实践

  • Python 2：始终显式地继承object，以获取新风格类的诸多优点。
  • Python 3：若代码需同时兼容Python 2和Python 3，则继承object；否则，可省略。

常见问题

问题1：在Python 2中使用Python 3风格的类定义会怎样？

在Python 2中使用Python 3风格（省略object）的类定义，会得到旧风格类。旧风格类不支持super()、@property和描述符等特性，可能导致代码出现难以调试的问题。

问题2：新风格类有什么缺点？

新风格类本身占用的内存更多，但除非创建大量类对象，否则这通常不是问题。
