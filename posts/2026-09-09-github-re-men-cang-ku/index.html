1. heygen-com/hyperframes

  • 仓库 URL：https://github.com/heygen-com/hyperframes
  • 简介：用 HTML 写代码，直接渲染成视频
  • 亮点：HyperFrames 的核心理念极其优雅：用你最熟悉的 HTML+CSS 来描述视频内容，然后自动渲染成高质量视频 🎬。它专为 AI Agent 设计，让 Agent 能像写网页一样生成视频。告别复杂的视频编辑软件，告别 ffmpeg 的各种参数地狱，用前端的方式做视频——这可能是 2026 年最优雅的视频生成方案。今天新增 2600+ Star，势头凶猛，强烈推荐前端和 AI 工作者关注！

2. jo-inc/camofox-browser

  • 仓库 URL：https://github.com/jo-inc/camofox-browser
  • 简介：AI Agent 专用隐身浏览器，轻松绕过 Cloudflare 和反爬检测
  • 亮点：做 AI Agent 的同学一定被 Cloudflare 挡过无数次 😤。Camofox Browser 是一个专为 Agent 设计的隐身无头浏览器，能够绕过 Cloudflare、各类 Bot 检测和反爬机制。它可以直接替换 Puppeteer/Playwright，零改动迁移。对于需要网页交互能力的 Agent 应用来说，这简直是救命稻草。日增 871 Star，实用度拉满！
