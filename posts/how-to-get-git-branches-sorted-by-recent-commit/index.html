常见问题

版本兼容性问题

部分命令需要特定的Git版本支持，如 git branch --sort 自Git 2.7.0版本起可用。在使用前，请确保你的Git版本符合要求。

排序异常问题

如果排序结果不符合预期，可能是由于Git配置问题或数据异常。可以尝试更新Git版本、清理缓存或检查配置文件。
