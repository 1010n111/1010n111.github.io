不采用白板面试的公司汇总

技术背景

传统的白板面试往往侧重于考察求职者对计算机科学 trivia 问题的掌握，这类问题与日常工作关联不大，不能很好地反映求职者的实际工作能力。而“不采用白板面试”则强调使用与日常工作相似的面试技术和问题，如解决实际问题、参与真实项目等，能更准确地评估求职者的能力和适应性。

实现步骤

  1. 明确目标：求职者首先要确定自己感兴趣的公司或岗位，然后在该列表中查找对应的公司。
  2. 了解面试流程：对于列表中的公司，仔细阅读其面试流程的描述，包括面试的阶段、形式和重点考察内容。
  3. 针对性准备：根据不同公司的面试要求，准备相应的技能和知识。例如，如果公司注重实际项目经验，求职者可以准备相关的项目案例和解决方案。
  4. 申请职位：按照公司的招聘流程，提交申请并参加面试。

最佳实践

  1. 提前研究：在申请职位之前，充分了解公司的业务、文化和技术栈，以便更好地适应面试要求。
  2. 展示实际能力：在面试过程中，注重展示自己的实际工作能力和解决问题的能力，而不仅仅是理论知识。
  3. 积极沟通：与面试官保持良好的沟通，表达自己的想法和思路，同时认真听取面试官的反馈。
  4. 持续学习：不断提升自己的技能和知识，以适应不同公司的面试要求。

常见问题

  1. 公司信息不准确：如果发现列表中的公司信息与实际面试情况不符，可以通过提交 PR 的方式进行修正。
  2. 筛选功能不足：如果需要对公司信息进行更复杂的筛选、排序或分组操作，可以使用 Airtable 或相关的 API 来实现。
  3. 面试难度差异：不同公司的面试难度和要求可能存在差异，求职者需要根据自己的实际情况进行准备。
