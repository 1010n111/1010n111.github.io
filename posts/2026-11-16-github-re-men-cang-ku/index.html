2026-11-16 Github热门仓库

2026-11-16 Github热门仓库

2026-11-16：AI 办公与代码评审新趋势

今天给大家挑选了几款能让 AI 代理更好工作、让代码审查更安全的热门项目。

🔥 今日精选

1. dream-num/univer

  • 仓库 URL：https://github.com/dream-num/univer
  • 简介：提供 AI 办公 SDK，轻松嵌入编辑、计算等功能。
  • 亮点：Univer 通过开放式 SDK 把文档编辑、表格计算、协同与文件处理全部模块化，开发者只需几行代码即可在自己的产品或 AI 代理中嵌入完整的办公能力。适合需要在业务系统中快速加入 AI 办公体验的前端或全栈团队，帮助提升交互效率 🚀。

2. alibaba/open-code-review

  • 仓库 URL：https://github.com/alibaba/open-code-review
  • 简介：面向大规模企业的混合式代码审查平台，支持 LLM 自动评论。
  • 亮点：该工具将确定性审查流水线与大模型 Agent 结合，实现行级智能评论、跨语言安全规则（如 XSS、SQL 注入）自动检测。企业研发只需配置规则，即可获得精准的代码质量反馈，显著降低人工审查成本并提升安全防护 🛡️。

3. NVIDIA/SkillEvaluator

  • 仓库 URL：https://github.com/NVIDIA/SkillEvaluator
  • 简介：多层次框架，用于评估 AI 代理技能的质量和影响。
  • 亮点：SkillEvaluator 提供质量门、语义重叠检测、合成评估数据生成以及实时行为评测等模块，让研发团队可以系统化、可复现地衡量每项 Agent Skill 对整体系统的贡献。适合需要对 AI 代理进行严格质量把控的科研或产品团队 📊。

⚡ 快速浏览

4. ag-ui-protocol/ag-ui

  • 仓库 URL：https://github.com/ag-ui-protocol/ag-ui
  • 简介：在前端引入 Agent-User Interaction 协议，实现 AI 代理与 UI 的自然交互。

5. google-labs-code/stitch-skills

  • 仓库 URL：https://github.com/google-labs-code/stitch-skills
  • 简介：提供标准化的 Agent Skills 库，可直接在 Stitch MCP 上调用，兼容多种编码代理。

6. backnotprop/plannotator

  • 仓库 URL：https://github.com/backnotprop/plannotator
  • 简介：一站式工作区，支持对代码进行标注、审阅并一键发送给 AI 代理反馈。

7. ChromeDevTools/chrome-devtools-mcp

  • 仓库 URL：https://github.com/ChromeDevTools/chrome-devtools-mcp
  • 简介：为 AI 代理量身定制的 Chrome DevTools，帮助调试和分析网页行为。

8. Tencent/LoopForge

  • 仓库 URL：https://github.com/Tencent/LoopForge
  • 简介：自托管工作流平台，编排 CodeBuddy、Codex 等代理并加入人工审批。

9. ggml-org/ggml

  • 仓库 URL：https://github.com/ggml-org/ggml
  • 简介：轻量级张量库，提供高效的机器学习算子，适合嵌入式模型部署。

10. elementalsouls/Claude-BugHunter

  • 仓库 URL：https://github.com/elementalsouls/Claude-BugHunter
  • 简介：聚合 82 条 Claude Code 漏洞检测技能，助力红队快速定位安全缺陷。

11. GoogleChrome/modern-web-guidance-src

  • 仓库 URL：https://github.com/GoogleChrome/modern-web-guidance-src
  • 简介：收集最新 Web 最佳实践，为编码代理提供更新指南。

12. tradermonty/claude-trading-skills

  • 仓库 URL：https://github.com/tradermonty/claude-trading-skills
  • 简介：面向投资者的 Claude Code 技能集，涵盖行情分析、图表绘制等功能。

以上项目各有千秋，快去挑一个试试，看看哪个最能提升你的工作流？
