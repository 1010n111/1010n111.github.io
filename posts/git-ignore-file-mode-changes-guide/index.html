让Git忽略文件模式（chmod）更改的方法

技术背景

在使用Git进行版本控制时，文件的执行权限（文件模式）更改有时会被Git记录，这可能会干扰正常的版本管理流程。例如，在不同的操作系统或文件系统之间切换时，文件的执行权限可能会发生变化，导致Git认为文件有更改，即使文件内容并未改变。
