2026-11-10 热门开源项目速览：AI 代理、社交账号探测与浏览器自动化

今天为大家挑选了几款近期在 GitHub 趋势榜上热度飙升的项目，涵盖 AI 技能、账号安全和浏览器自动化等实用方向。

🔥 今日精选

1. anthropics/skills

  • 仓库 URL：https://github.com/anthropics/skills
  • 简介：提供可复用的 AI 代理技能库。
  • 亮点：🤖 anthropics/skills 为 AI 代理提供可复用的技能库，开发者只需编写简短的 Python 函数即可定义新技能，系统自动注册并通过统一接口调用。适合想快速构建具备搜索、计算或工具调用能力的聊天机器人，也能帮助科研团队把实验流程模块化，让模型在不同任务间无缝切换。

2. sherlock-project/sherlock

  • 仓库 URL：https://github.com/sherlock-project/sherlock
  • 简介：批量查询社交平台用户名占用情况。
  • 亮点：🔍 sherlock-project/sherlock 能批量检测全球数百个社交平台上的用户名是否被占用，输入一组昵称即可输出对应的账号链接或不存在提示。它基于 Python 编写，支持自定义站点列表，适合渗透测试、安全研究以及个人品牌审计，帮助用户快速发现潜在的社交媒体泄露或抢注风险。

3. vercel-labs/agent-browser

  • 仓库 URL：https://github.com/vercel-labs/agent-browser
  • 简介：面向 AI 代理的浏览器自动化 CLI。
  • 亮点：🖥️ vercel-labs/agent-browser 提供面向 AI 代理的浏览器自动化 CLI，利用 Rust 实现高性能无头浏览，支持页面抓取、表单填写和交互脚本。只需在命令行传入指令或让语言模型生成脚本，即可让 AI 实时获取网页信息并作出决策，适合构建需要联网查询的聊天机器人或自动化测试工具。
