避免使用过长的 case 语句

如果 case 语句中的 when 条件过多，可以考虑使用哈希表来替代，以提高代码的可读性和可维护性。

注意 === 运算符的使用

在 case/when 语句中，Ruby 使用 === 运算符进行比较。不同的类对 === 运算符有不同的实现，需要注意其行为。例如，在比较对象的类时，要确保正确使用 === 运算符：

常见问题

case 语句中使用类进行比较时的问题

在 case 语句中直接使用对象的类进行比较可能会得到意外的结果，因为 === 运算符在处理类时的行为与预期不同。可以通过直接使用对象而不是对象的类来解决这个问题。

忘记 else 语句

如果 case 语句中没有 else 语句，当所有 when 条件都不满足时，不会执行任何代码。在需要处理默认情况时，应该添加 else 语句。
