2026-11-12 Github热门仓库

2026-11-12：今日 GitHub 热门项目精选

每天挑选几款社区热议的开源项目，看看它们能为你的开发带来哪些新思路。

🔥 今日精选

1. meta/astryx

  • 仓库 URL：https://github.com/meta/astryx
  • 简介：高度可定制、支持 AI 代理的开源设计系统
  • 亮点：meta/astryx 提供完整的 UI 组件库和主题体系，全部基于 TypeScript，可自行配置颜色、布局等细节；同时内置对 AI 代理的适配接口，方便在聊天机器人或智能助手中直接调用 UI。适合前端团队想快速搭建统一视觉体系，又希望未来接入生成式 AI 的项目。🚀

2. addyosmani/agent-skills

  • 仓库 URL：https://github.com/addyosmani/agent-skills
  • 简介：为 AI 编码代理提供生产级工程技能集合
  • 亮点：addyosmani/agent-skills 汇聚了文件操作、依赖管理、单元测试等常用开发任务的实现代码，封装为可直接在 LLM 驱动的编码代理中调用的函数库。通过简单的 Prompt 指令即可让 AI 自动完成代码生成、格式化、提交等流程，大幅提升自动化效率。适合希望让 AI 编码更可靠、符合团队规范的开发者。🤖

3. vercel-labs/agent-browser

  • 仓库 URL：https://github.com/vercel-labs/agent-browser
  • 简介：面向 AI 代理的浏览器自动化命令行工具
  • 亮点：vercel-labs/agent-browser 基于 Rust 构建，提供轻量的 CLI，可让 AI 代理像人类一样在浏览器中点击、输入、截图等。使用时只需在提示中加入对应指令，工具会启动无头浏览器执行操作并返回结果，帮助实现网页数据抓取、表单自动化等场景。适合需要让 LLM 直接与前端页面交互的研发人员。🛠️

⚡ 快速浏览

4. ZhuLinsen/daily_stock_analysis

  • 仓库 URL：https://github.com/ZhuLinsen/daily_stock_analysis
  • 简介：LLM 驱动的多市场股票实时分析平台，集行情、新闻与决策看板于一体。

5. GoogleChrome/modern-web-guidance-src

  • 仓库 URL：https://github.com/GoogleChrome/modern-web-guidance-src
  • 简介：Chrome 官方发布的现代 Web 开发指引源码，示例丰富、可直接参考。

6. shadcn/improve

  • 仓库 URL：https://github.com/shadcn/improve
  • 简介：利用强大模型审计代码并生成轻量计划，让后续模型以更低成本执行修复。

7. we-promise/sure

  • 仓库 URL：https://github.com/we-promise/sure
  • 简介：面向所有人的个人理财应用，强调社区共建与开源透明。

8. homeassistant-ai/ha-mcp

  • 仓库 URL：https://github.com/homeassistant-ai/ha-mcp
  • 简介：通过 Claude、ChatGPT 等 AI 助手配置 Home Assistant，实现语音与自动化的深度融合。

9. openai/codex-security

  • 仓库 URL：https://github.com/openai/codex-security
  • 简介：Codex Security 提供 CLI 与 TypeScript SDK，帮助快速定位并修复代码安全漏洞。

10. TheAlgorithms/Java

  • 仓库 URL：https://github.com/TheAlgorithms/Java
  • 简介：收录完整的 Java 算法实现，适合作为学习与面试复习的参考库。

以上项目各有亮点，快挑一个试试，看看哪款最能激发你的灵感吧！
