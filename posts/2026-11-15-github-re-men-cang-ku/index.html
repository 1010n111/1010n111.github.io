2026-11-15 Github热门仓库

2026-11-15 今日精选：15 大 GitHub 热门项目速览

每天都有新工具冲击开发者的工作流，今天挑出几款最值得一试的项目。

🔥 今日精选

1. backnotprop/plannotator

  • 仓库 URL：https://github.com/backnotprop/plannotator
  • 简介：统一工作区，团队可与 AI 代理协作标注代码，一键反馈。
  • 亮点：在多人协作时，代码审查常被评论分散、反馈不及时所困。plannotator 通过浏览器工作区把代码、注释、AI 代理统一呈现，支持标注、审查、生成反馈并一键发送，使用方式只需在浏览器打开项目，即可邀请团队成员和 LLM 共同编辑。适合需要高效代码审查、AI 辅助写作的开发者和产品团队。🚀

2. alibaba/open-code-review

  • 仓库 URL：https://github.com/alibaba/open-code-review
  • 简介：混合架构审查，结合流水线与 LLM，提供行级评论和安全规则。
  • 亮点：大规模代码库的安全审查往往耗时且易漏。open-code-review 采用确定性流水线加上 LLM 代理，能够在提交阶段自动检测 NPE、线程安全、XSS、SQL 注入等风险，并在行级给出精准评论。使用时只需在 CI 中配置对应规则，即可在企业或开源项目中实现高速、可靠的代码审查。🔧

3. QwenLM/qwen-code

  • 仓库 URL：https://github.com/QwenLM/qwen-code
  • 简介：在终端运行的开源 AI 编码助手，支持即时代码生成与调试。
  • 亮点：在纯 CLI 环境下写代码时常缺少即时帮助。qwen-code 直接嵌入终端，提供自然语言指令生成代码、解释错误、自动调试等功能。安装后在任意目录执行 qwen-code 即可与 LLM 对话，适合习惯使用命令行的开发者、学习者以及需要快速原型的团队。🤖

5. ChromeDevTools/chrome-devtools-mcp

  • 仓库 URL：https://github.com/ChromeDevTools/chrome-devtools-mcp
  • 简介：面向 AI 代理的 Chrome DevTools 扩展，便于在浏览器中调试代码交互。

6. dream-num/univer

  • 仓库 URL：https://github.com/dream-num/univer
  • 简介：可将 AI 办公能力嵌入产品，提供编辑、计算、协作等模块的 SDK。

7. ag-ui-protocol/ag-ui

  • 仓库 URL：https://github.com/ag-ui-protocol/ag-ui
  • 简介：定义 Agent 与前端的交互协议，帮助前端快速接入 AI 代理。

8. ashhart/TensorFold

  • 仓库 URL：https://github.com/ashhart/TensorFold
  • 简介：跨平台 LLM 推理引擎，支持 Metal、CUDA 与 Vulkan，加速模型部署。

9. JuliusBrussee/caveman

11. we-promise/sure
