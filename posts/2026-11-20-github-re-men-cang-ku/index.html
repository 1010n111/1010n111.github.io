2026-11-20 Github热门仓库

2026-11-20 Github热门仓库

2026-11-20 热门开源精选：AI 代码、代理与工具大盘点

今天为你挑选了几款最有意思的开源项目，看看它们能帮你解决哪些痛点。

🔥 今日精选

1. elementalsouls/Claude-BugHunter

  • 仓库 URL：https://github.com/elementalsouls/Claude-BugHunter
  • 简介：面向 Claude Code 的漏洞猎取技能集，提供 82 条技能和攻击矩阵。
  • 亮点：Claude‑BugHunter 整合了 82 条漏洞猎取技能和 15 条快捷指令，涵盖 24 类核心漏洞以及企业身份、基础设施攻击矩阵。使用者只需在 Claude Code 中加载技能包，即可快速生成漏洞报告、自动化渗透步骤，适合安全团队、红队以及希望在代码审计中加入 AI 辅助的开发者。🐞

2. obra/superpowers

  • 仓库 URL：https://github.com/obra/superpowers
  • 简介：一套可执行代理技能的开发框架，兼容多语言工作流。
  • 亮点：Superpowers 提供了一个基于 Shell 的代理技能框架，帮助开发者以声明式方式组织 AI Agent 的能力。通过统一的 skill 定义与执行环境，团队可以快速搭建、复用和调试复杂的自动化流程，尤其适合构建跨语言、多模态的智能应用。🚀

3. firecrawl/firecrawl

  • 仓库 URL：https://github.com/firecrawl/firecrawl
  • 简介：统一 API 接入网页抓取与搜索，提升智能体数据获取效率。
  • 亮点：Firecrawl 将网页爬取、搜索以及 550+ 数据源整合到同一个 API，开发者只需一次请求即可获得结构化内容。它支持自动化抓取、实时搜索和多语言解析，极大简化了为 LLM 或自动化 Agent 构建知识库的流程，特别适合需要快速获取网络信息的 AI 项目。🔍

⚡ 快速浏览

4. HKUDS/CLI-Anything

  • 仓库 URL：https://github.com/HKUDS/CLI-Anything
  • 简介：把任意软件包装成 CLI 接口，方便在终端或脚本中调用。

5. jingyaogong/minimind

  • 仓库 URL：https://github.com/jingyaogong/minimind
  • 简介：两小时训练出 64M 小模型，适合资源受限的 LLM 实验。

6. cursor/plugins

  • 仓库 URL：https://github.com/cursor/plugins
  • 简介：官方 Cursor 插件规范与示例集合，帮助扩展编辑器功能。

7. nginx/nginx

  • 仓库 URL：https://github.com/nginx/nginx
  • 简介：官方 NGINX 开源仓库，持续维护高性能 Web 服务器。

8. openvinotoolkit/openvino

  • 仓库 URL：https://github.com/openvinotoolkit/openvino
  • 简介：OpenVINO 工具套件，助力 AI 推理模型的优化与部署。

9. cathrynlavery/diagram-design

  • 仓库 URL：https://github.com/cathrynlavery/diagram-design
  • 简介：提供 45 种 AI 编码工具的交互式示意图，直接在浏览器查看。

10. mvanhorn/last30days-skill

  • 仓库 URL：https://github.com/mvanhorn/last30days-skill
  • 简介：聚合 Reddit、X、YouTube 等平台信息，生成可靠的主题摘要。

11. google-labs-code/stitch-skills

  • 仓库 URL：https://github.com/google-labs-code/stitch-skills
  • 简介：为 Stitch MCP 服务器提供的标准化 Agent Skills 库，兼容多种编码代理。

12. mjmirza/app-store-compliance

  • 仓库 URL：https://github.com/mjmirza/app-store-compliance
  • 简介：收录 117 条常见上架审查坑点，提供自动化合规检查脚本。

13. Tracer-Cloud/opensre

  • 仓库 URL：https://github.com/Tracer-Cloud/opensre
  • 简介：面向 CI/CD 的可靠性监控代理，帮助发现并预防构建故障。

14. toeverything/AFFiNE

  • 仓库 URL：https://github.com/toeverything/AFFiNE
  • 简介：下一代开源知识库，融合笔记、白板和项目管理功能。

15. XiaoYouChR/Ghost-Downloader-3

  • 仓库 URL：https://github.com/XiaoYouChR/Ghost-Downloader-3
  • 简介：全能下载器，支持多平台高速下载并自动整理文件。

16. zhouxiaoka/autoclip

  • 仓库 URL：https://github.com/zhouxiaoka/autoclip
  • 简介：AI 视频剪辑工具，一键将长视频转短片并生成字幕和封面。
