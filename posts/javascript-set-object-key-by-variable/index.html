最佳实践

  • 在现代JavaScript开发中，优先使用ES6及以上的语法，因为计算属性名使代码更简洁易读。
  • 尽量使用 const 或 let 代替 var 来声明变量，避免变量提升带来的问题。

常见问题

未使用方括号

如果直接使用变量作为键名而不使用方括号，JavaScript会将变量名作为字符串键名，而不是变量的值。
