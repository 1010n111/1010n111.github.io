2026-09-10 Github热门仓库

今天炸场了！5 分钟星标暴涨 4650 的「ADHD 友好」编程神器，还有让代码说话的交易框架｜GitHub Trending 日报（2026-09-10）

今天的 GitHub Trending 简直是 AI 开发者的狂欢夜，从治编码强迫症的「ADHD 模式」到能画杂志级图表的设计神器，个个都是暗戳戳爆单的狠货。看到就是赚到，记得收藏，今天不剁手冲动，只剁代码冲动 😎

🔥 今日精选

1. ayghri/i-have-adhd

  • 仓库 URL：https://github.com/ayghri/i-have-adhd
  • 简介：给编码 Agent 装上「ADHD 模式」：别把答案埋进 800 行废话里，直说重点。
  • 亮点：今天最炸的仓库没有之一，单日暴涨 4650 星！它专门定制了一套 ADHD 友好的输出技能，让 Claude 这样的编程 Agent 打破「长篇大论找答案」的老毛病——直接、简短、直击要害，像有个小助手在你耳边喊「答案在这，别翻页」🧠。对于懒得翻长日志、一看到大段输出就头疼的开发者，简直是救星。配置几行 skill 就能用，开源友好，今天不火真的没天理。

2. cathrynlavery/diagram-design

  • 仓库 URL：https://github.com/cathrynlavery/diagram-design
  • 简介：38 种杂志级编辑图表模板，自带 HTML+SVG，告别 Mermaid 的「塑料感」。
  • 亮点：设计师给 AI 的降维打击：内置 38 种「编辑级」图表类型，全部是自包含的 HTML+SVG，无需任何依赖，拖进 Claude Code、Codex 就能出图 slay 全场 🎨。主打「无阴影、无 Mermaid 烂活」，输出直接对标科技杂志插图水准。单日冲上 2249 星说明一切——想要你的 PPT 和文档插图从「程序员手绘风」进化成「大厂设计稿」，这一个仓库就够了。

3. TauricResearch/TradingAgents

  • 仓库 URL：https://github.com/TauricResearch/TradingAgents
  • 简介：多 Agent LLM 金融交易框架：让一群 AI 互相对喷观点，再帮你做交易决策。
  • 亮点：把华尔街模拟进了你的电脑：一个多 Agent 金融交易框架，让多个 LLM 扮演分析师、研究员、风向标互相「开会」，从数据到观点层层碰撞，最终输出交易决策 📈。总星数已破 10 万，是今天榜单里绝对的重量级选手。它不是让你闭眼梭哈的暴富工具，而是理解「AI 怎么从混沌信息里抓出投资逻辑」的教科书级实验场，技术宅也能体验一把模拟盘操盘手的快乐。
