今日热点仓库精选 | 2026-11-24

今天为大家挑选了 GitHub Trending 中最值得关注的项目，涵盖安全、AI 与开发利器。

🔥 今日精选

1. elementalsouls/Claude-BugHunter

  • 仓库 URL：https://github.com/elementalsouls/Claude-BugHunter
  • 简介：为 Claude Code 提供 84 条漏洞抓取技能与攻击矩阵的工具包。
  • 亮点：Claude-BugHunter 整合了 84 条针对 24 类核心漏洞的技能、15 条快捷指令以及 681 条报告模板，帮助安全研究员在 Claude Code 环境中快速定位、复现并报告安全问题。适合红队、渗透测试以及企业安全团队使用，配合身份与基础设施攻击矩阵，可直接在对话中调用，省去手动搜集情报的繁琐。🎯

2. obra/superpowers

  • 仓库 URL：https://github.com/obra/superpowers
  • 简介：一套让 AI 代理具备可编程技能的开发框架。
  • 亮点：superpowers 提供了声明式的技能定义、状态管理与自动化工作流，让开发者能够像搭积木一样为 AI 代理添加自定义功能。支持 Shell 脚本、HTTP 调用等多种执行方式，配合内置的 CI/CD 机制，可在团队中统一管理和复用技能，适合想把 AI 融入日常开发的团队使用。

3. firecrawl/firecrawl

  • 仓库 URL：https://github.com/firecrawl/firecrawl
  • 简介：通过单一 API 调用 550+ 数据源，实现爬取、搜索与结构化。
  • 亮点：firecrawl 将网页爬取、搜索与数据清洗统一到一个 RESTful API，开发者只需提供目标 URL 即可获得结构化文本、摘要或全文。内置 550 多家数据提供商的接入，支持多语言、分页与速率控制，特别适合构建 LLM 知识库或让智能代理快速获取最新信息。🔥
