🔥 今日精选

1. thedotmack/claude-mem

  • 仓库 URL：https://github.com/thedotmack/claude-mem
  • 简介：跨会话持久上下文，让 AI 记忆延续。
  • 亮点：为每个 AI 代理提供跨会话的持久上下文，自动记录交互并用 LLM 压缩后注入后续对话。使用时只需在项目中引入库，即可在 Claude Code、OpenClaw、Gemini 等多种模型间共享记忆，适合需要长期记忆或连续任务的开发者和企业。

2. lightpanda-io/browser

  • 仓库 URL：https://github.com/lightpanda-io/browser
  • 简介：AI 专用轻量无头浏览器，Zig 实现。
  • 亮点：专为 AI 与自动化打造的无头浏览器，基于 Zig 实现高效轻量。直接通过 API 启动、渲染、脚本执行，无需图形界面，兼容主流浏览器特性，适合爬虫、机器学习数据采集以及 AI 驱动的网页交互场景。

3. Donchitos/Claude-Code-Game-Studios

  • 仓库 URL：https://github.com/Donchitos/Claude-Code-Game-Studios
  • 简介：Claude Code 版全功能游戏工作室。
