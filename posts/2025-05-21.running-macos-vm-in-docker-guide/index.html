在Windows上运行

  1. 安装WSL2：在管理员PowerShell中运行wsl --install，确认WSL2已启用，可使用wsl -l -v查看。
  2. 配置.wslconfig：在C:/Users/<Your_Name>/.wslconfig文件末尾添加nestedVirtualization=true。
  3. 检查KVM：进入WSL发行版，使用kvm-ok命令检查KVM是否启用，若未启用，使用sudo apt -y install bridge-utils cpu-checker libvirt-clients libvirt-daemon qemu qemu-kvm安装。
  4. 安装Docker for Windows：安装后在设置中勾选“Use the WSL2 based engine”和“Enable integration with my default WSL distro”。
  5. 安装x11-apps：使用sudo apt install x11-apps -y安装。

减小镜像大小

  1. 启动容器，使用du -sh *从/目录开始查找可删除大文件的目录。
  2. 启用trim：sudo trimforce enable，然后重启。
  3. 清空磁盘空空间：dd if=/dev/zero of=./empty && rm -f empty。
  4. 复制出qcow镜像：docker cp stoppedcontainer:/home/arch/OSX-KVM/mac_hdd_ng.img .。
  5. 检查并修复镜像错误：qemu-img check -r all mac_hdd_ng.img。
  6. 转换镜像格式：qemu-img convert -O qcow2 mac_hdd_ng.img deduped.img。
  7. 可选：进一步压缩镜像：qemu-img convert -c -O qcow2 deduped.img compressed.img。
