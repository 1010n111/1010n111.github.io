🔥 今日精选

1. mattpocock/skills

  • 仓库 URL：https://github.com/mattpocock/skills
  • 简介：来自 TypeScript 大神的实战技能库，全部源自本人的 .agents 目录
  • 亮点：mattpocock 是前端圈无人不知的类型体操大师，这次他把自己日常使用的 Agent 技能库直接开源了！全部代码来自他本人真实使用的 .agents 目录，一手的工程实践经验，绝非纸上谈兵。无论你用的是 Claude Code、Codex 还是其他 Agent 工具，都能从中学到如何把 AI 编程助手调教成真正靠谱的‘资深工程师’。今日新增 2200+ Star，热度爆表，适合所有想提升 Agent 使用姿势的开发者。

2. DietrichGebert/ponytail

  • 仓库 URL：https://github.com/DietrichGebert/ponytail
  • 简介：让 AI Agent 拥有‘最懒资深工程师’思维的神奇技能包
  • 亮点：ponytail 的核心哲学只有一句话：最好的代码是永远没写出来的那些代码！它让你的 AI Agent 学会像办公室里最懒的资深工程师那样思考——能用现成的不重复造轮子，能少写就少写，优先考虑删除和简化而非堆砌功能。这个‘反内卷’思路非常反直觉却极其实用，能有效帮团队砍掉大量冗余代码、降低维护成本。今日暴涨 1500+ Star，足见大家苦‘过度设计’久矣，轻松有趣的风格搭配硬核实用性，强烈推荐一试！

3. magnitudedev/magnitude

  • 仓库 URL：https://github.com/magnitudedev/magnitude
  • 简介：开源本地推理服务器，插进你现成 Agent 立刻起飞
  • 亮点：magnitude 是一款开源推理服务器，核心卖点是把最适合你本地硬件的模型跑起来，然后无缝接入你已经在用的 Agent 工具——支持 Pi、OpenCode、Hermes、Codex、Claude Code、Cline 等一大票主流方案。对于追求数据隐私、想摆脱云端 API 依赖的开发者来说，它就是那个让本地模型优雅落地的‘胶水层’。今天一天涨了 600+ Star，作为新晋仓库冲劲十足，适合所有想玩本地大模型却又不想折腾接入的玩家。
