最佳实践

  • 当需要修改多个元素的 href 属性时，使用 jQuery 的 attr 或 prop 方法可以一次性完成操作，提高代码效率。
  • 如果只需要修改单个元素的 href 属性，使用纯 JavaScript 的 setAttribute 方法可能更简洁。
  • 在使用选择器时，尽量使用更精确的选择器，避免意外修改不需要的元素。

常见问题

attr 和 prop 方法有什么区别？

attr 方法获取的是 HTML 属性，而 prop 方法获取的是 DOM 属性。在大多数情况下，使用 prop 方法更合适，尤其是从 jQuery 1.6 版本开始。
