今日精选 GitHub Trending 项目盘点 - 2026-11-09

每天都有新奇的开源项目冒出来，这里挑出三款最值得关注的，帮你快速上手。

🔥 今日精选

1. sherlock-project/sherlock

  • 仓库 URL：https://github.com/sherlock-project/sherlock
  • 简介：跨平台用户名搜索工具，快速定位社交媒体账号。
  • 亮点：Sherlock 能帮你在上百个社交平台上批量查询指定用户名是否已被占用，适合安全研究员、渗透测试员以及需要核查品牌舆情的运营人员。只需一行命令输入用户名列表，工具自动并发请求并输出可疑账号链接，配合脚本可进一步抓取公开信息，快速定位潜在风险。

2. vercel-labs/agent-browser

  • 仓库 URL：https://github.com/vercel-labs/agent-browser
  • 简介：面向 AI 代理的浏览器自动化 CLI 工具。
  • 亮点：agent-browser 提供基于 Rust 的轻量化命令行，能让 AI 代理直接控制浏览器完成页面抓取、表单填写或交互脚本执行。开发者只需写几行提示词或调用简单 API，即可在本地或云端启动无头浏览器，适用于构建搜索增强、自动化测试或信息抽取的智能应用。

3. anthropics/skills

  • 仓库 URL：https://github.com/anthropics/skills
  • 简介：公开的 Claude 代理技能库。
  • 亮点：anthropics/skills 收集了多种可直接在 Claude API 中调用的 Agent Skills，涵盖文本摘要、代码生成、数据查询等常用场景。使用者只需在提示词中声明 skill 名称，即可让 Claude 自动加载对应功能，降低自行实现复杂逻辑的门槛，特别适合想快速原型化 AI 助手的开发者。
