2026-09-13 Github热门仓库

🔥 今日 GitHub 爆款盘点（2026年9月13日）：当你能从浏览器”发射”间谍卫星，世界突然变得有点酷

周末的 GitHub Trending 从不让人失望，今天有”上帝视角”的间谍卫星模拟器、数学建模的作弊神器，还有会写歌的 AI。准备好一口气看完这场开源盛宴了吗？🚀

🔥 今日精选

1. bilawalsidhu/gods-eye-view

  • 仓库 URL：https://github.com/bilawalsidhu/gods-eye-view
  • 简介：浏览器里的间谍卫星模拟器，数据却是真实的🛰️
  • 亮点：想在浏览器里体验一把真正的”上帝视角”吗？这个项目把照片级真实的 3D 地球搬进网页，让你模拟间谍卫星实时俯瞰地表，而所有数据都来自真实的开源情报。今天一天就涨了 2200+ 星，热度断崖式领先。无需安装任何客户端，打开网址即可”发射卫星”，无论你是地理迷、卫星控还是情报爱好者，这都是一次教科书级别的开源脑洞体验。

2. jihe520/MathModelAgent

  • 仓库 URL：https://github.com/jihe520/MathModelAgent
  • 简介：数学建模界的”一键外挂”，自动生成可直接提交的论文🤖
  • 亮点：数学建模比赛的时间有多紧，懂的都懂。这个 Agent 就是为此而生：从读题、建模、求解到最后自动生成一份结构完整的论文，全程自动化，堪比请了个 24 小时不睡觉的队友。📐 内置数学建模所需的 skills 和工具链，今天涨了 260+ 星。对准备参加数模竞赛的本科生和研究生来说，这几乎是”保姆级”的开源福利。

3. multimodal-art-projection/YuE

  • 仓库 URL：https://github.com/multimodal-art-projection/YuE
  • 简介：能做零样本翻唱、还能”导演”式编辑音乐的生成式 AI 作曲模型🎵
  • 亮点：想要旋律里有歌单之外的惊喜？YuE2 是目前前沿的音乐生成模型，支持符号化规划、零样本翻唱和”智能体式”音乐编辑——你可以像导演一样指挥 AI 生成、修改并混排一段完整歌曲。今天新增 210 星，说明”让 AI 写歌”这件事终于跨过了玩具阶段。对于音乐创作者和播客玩家，这个仓库值得好好蹲一下。
