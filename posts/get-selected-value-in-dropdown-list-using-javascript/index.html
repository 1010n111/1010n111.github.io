常见问题

1. Internet Explorer兼容性问题

在旧版本的Internet Explorer中，使用 e.options(e.selectedIndex).value 这种圆括号的写法可能会正常工作，但在其他浏览器中会报错。正确的写法是使用方括号 e.options[e.selectedIndex].value。
