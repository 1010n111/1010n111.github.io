最佳实践

  • 优先使用适合当前 SQL Server 版本的函数，如 SQL Server 2017 及以上版本使用 STRING_AGG 函数，简单高效。

常见问题

  • NULL 值问题：若行中有 NULL 名称值，使用 COALESCE 时会导致结果不正确，可通过过滤 NULL 或替换 NULL 为指定值来解决。
